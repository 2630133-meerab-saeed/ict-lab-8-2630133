Task 1: Questions & Answers

Q1: What does colspan do and what does rowspan do?
Ans: colspan merges a cell horizontally across multiple columns,
while rowspan merges a cell vertically across multiple rows.

Q2: How many cells must the second Monday row have, and why?
Ans: It must have only 2 cells because the first Monday cell
uses rowspan="2" and already covers the first column of the second row.

Q3: Why are column titles written with <th> instead of <td>?
Ans: <th> defines header cells, which appear bold and centered
by default and improve accessibility for screen readers.

Q4: Why is the table split into thead, tbody and tfoot?
Ans: It groups the header, main data, and summary rows separately
for better semantic structure, CSS styling, and printing.
