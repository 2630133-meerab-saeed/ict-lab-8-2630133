Task 3: Questions & Answers

1. Can both radio buttons be selected? Difference in behaviour vs checkboxes?
Ans: No, only one radio button can be selected because they share the same name.
Checkboxes allow selecting multiple options independently at the same time.

2. What is the difference between a <button> tag and an <input type="submit">?
Ans: <input type="submit"> is an empty tag that only displays plain text.
<button> is a container tag that can hold text, icons, images, or HTML formatting.

3. How do you choose more than one option with the mouse in a multiple select list?
Ans: Hold down the Ctrl key (Windows) or Cmd key (Mac) on the keyboard
while clicking multiple options with the mouse.

Task 4: Questions & Answers

(a) Why is a password sent with POST instead of GET?
Ans: GET appends form data to the URL, making passwords visible in the address bar,
browser history, and server logs. POST hides data inside the HTTP request body for security.

(b) Why is a field that has no name attribute missing from the submitted data?
Ans: Form data is sent to the server as name=value pairs. Without a name attribute,
the browser cannot identify the field and skips it during submission.

(c) What extra technology does a real website need to receive and store form data?
Ans: A real website needs a server-side backend language (such as PHP, Node.js, or Python)
and a database (such as MySQL or MongoDB) to receive and store submitted form data.
